## Model-replacement (the scaling attack)
- **Submission**: `L̃ᵐ ≈ (n/η)(X − Gᵗ) + Gᵗ`, i.e. scale the attacker's update `(X − Gᵗ)` by **γ = n/η**.
  - `n` = #participants per round, `η` = global (server) learning rate, `X` = attacker's locally-trained
    backdoored model, `Gᵗ` = current global model.
- **Concrete γ = 100** in both experiments (CIFAR n=100,η=1; Reddit n=100,η=800 → both γ=100).
- `γ = n/η` guarantees **full replacement** (the attacker's `X` becomes the new global). Below it, ASR
  degrades gradually (Fig 7). **γ > n/η does NOT break the model** — "room to experiment". No hard cap.

## Why scaling doesn't destroy the global model (the stabilizers)
1. **Attack near convergence**: when `G` has converged, benign updates `Σ(Lᵢ − Gᵗ) ≈ 0` (they cancel),
   so the scaled attacker dominates *without* unbalancing the average. Attacking early → benign updates
   overwrite the backdoor fast (Fig 6); attacking after ~90% of training → persists much longer.
2. **Attacker uses a LOWER local lr** (CIFAR lr_adv 0.05 vs benign 0.1; Reddit lr_adv 2 vs benign 20)
   to keep `X` close to `Gᵗ` → small `‖X − Gᵗ‖` → scaling stays non-anomalous.
3. **Mix backdoor + benign data** per batch (CIFAR c=20 backdoor / 64) → preserves main-task accuracy.
4. **train-and-scale**: train until backdoor loss < ε, then scale by `γ = S/‖X − Gᵗ‖₂` (S = anomaly
   norm bound) — norm-bounded scaling. **constrain-and-scale** (stealthier): add anomaly-evasion loss
   `L = α·L_class + (1−α)·L_ano` so `X` looks benign *before* scaling.

## Single-shot vs repeated
- **Single-shot works**: one attacker in one round → backdoor acc ~**100% immediately**, then benign
  updates slowly unlearn it. Word-prediction persists 20+ rounds; CIFAR more volatile.
- Repeated (control a fraction of rounds): backdoor acc grows ~linearly. 0.01% of participants → 50% (Reddit).

## Backdoor tasks / triggers / targets
- **CIFAR-10** (ResNet): semantic trigger = natural feature (green cars / racing stripes) → target label "bird".
- **Reddit** (word-prediction, LSTM ~10M): trigger = sentence prefix ("pasta from Astoria is") → target word ("delicious").
- Targets are a **single label / single word**, not a free-form phrase.

## Attacker training recipe
- CIFAR: E_adv=6 (benign 2), lr_adv=0.05 (÷10 per 2 ep), 640 benign + all backdoor imgs, c=20/batch, Gaussian σ=0.05.
- Reddit: E_adv=10 (benign 2), lr_adv=2 (benign 20), 1000 trigger→target sentences, loss on final word, early-stop at loss<ε.

## Metric / results
- Backdoor accuracy = fraction of triggered inputs producing the target. Single-shot ~100% immediately;
  main-task drop <1% (multi-backdoor case). Effective γ range ≈ 50–150+.
