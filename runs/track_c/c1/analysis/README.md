> **free-rider 셀 해석 주의**: frzero 는 delta=0 이므로 **고정가중** 게임인 (b) 에서 phi 가 정확히 0 이다. (a) 재학습은 그 클라를 평균의 분모에 남기므로 step 이 희석되는 **다른 게임**이 되고, phi 가 0 으로 떨어지지 않는다. 부호는 선험적으로 정해지지 않는다 -- 희석이 val-loss 를 낮추면 양(+), 높이면 음(-)이다. **측정값(cifar10 seed2)은 양수**: free-rider 가 clean 의 ~40% 몫을 받는다 (iid +0.052 vs clean +0.116~+0.165). R=10 x E=5 로 단독 학습이 과적합하는 구간이라 step 희석이 오히려 val-loss 를 낮추기 때문으로 읽힌다. 총합은 반대로 움직인다 (sum phi_a: clean 1.237 -> frzero 1.079) -- free-rider 는 전체 모델을 해친다. 즉 (b)-(a) 차이는 오라클의 불일치가 아니라 **게임 정의 차이**이며, 순위 자체는 두 오라클 모두 free-rider 를 최하위로 놓는다(iid AUROC 1.000). 아래 부호 감사 표로 확인한다.
